# Salmon
A simple, minimal web server made with rust for the initial purpose to learn
deeply the rust programming language by making a small sized project with
great value. For this reason, this project is not intended to be implemented
in any other web development project as it's not assured it will be well
maintained, optimized or secure.

Before starting, a research has been done in how this project is gonna be
accomplished. The project is not a web development framework, a framework is
far more complicated and intended to be used for developing dynamic web 
applications. A web server is much more simplier than that, it only involves
a server that can process HTTP requests and give an answer back.
