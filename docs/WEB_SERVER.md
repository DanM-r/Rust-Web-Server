## Web server definition

Computer that stores the web server software and website component files. The
web server software includes several parts that control how users access hosted
files. At minimum this is an HTTP server that understands URLs and communicates
over HTTP.

- Its better to host the web server on the cloud.

## Web server types

- **Static**: or stack, HTTP server that send the hosted files as is to browser
- **Dynamic**: makes use of an application server and a database. The app server
manipulates the hosted files before sending them to HTTP server.

## HTTP on web servers

The way web servers communicate their resources to browsers.

## Application servers

Most developers dont have to create their own servers from scratch. If its a
requirement, then there are server frameworks. A small number of developers
need to build their own server completely from scratch. 

## Server-side website programming

Create dynamic websites. In the modern world of web development, learning about
server-side development is highly recommended.
