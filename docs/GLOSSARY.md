# Glossary of Concepts

- **Resources**: target of HTTP request identified by a *Uniform Resource
Identifier (URI)*.
- **Representations**: reflect the state of a resource in a given period of
time. Set of representation metadata and in some cases a data stream.
- **Connections**: over a reliable transport or session layer
- **Clients/Servers**: roles programs take over a connection. 
- **Messages**: Encapsulation of data interchanged over the connection. Request
and Respond message exist for Client/Server respectively.
- **User agents**: any client program.
- **Origin server**: originate authorative responses.
- **Intermediaries**: proxy, gateway or tunnel that satisfy a chain connection.
- **Caches**: local storage of previous responses.
